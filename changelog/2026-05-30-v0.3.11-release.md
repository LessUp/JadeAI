# v0.3.11

发布日期：2026-05-30

## PDF 导出修复

- 修复 `swiss` 模板在分页边界附近把整条工作/项目经历整体推到下一页的问题，减少页尾大块空白。
- 调整 `swiss` 模板的 section header 包裹宽度，让 section 恰好从新页顶部开始时的页眉视觉更完整。
- 新增 `swiss-page-gap` PDF 回归 fixture，锁住“第一页必须出现目标经历条目”和“导出 header 必须保持加宽”两个关键回归点。
