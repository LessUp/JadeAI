# v0.3.6

发布日期：2026-05-11

## 新功能

- 新增**简历本地版本历史**，自动保存后可从浏览器本地恢复旧版本
- 将撤销 / 重做升级为**完整草稿级别**，覆盖标题、模板、主题、语言和模块内容
- 编辑器新增**版本历史面板**，支持查看与恢复历史版本

## 功能完善

- 导入、翻译覆盖、AI 回写、主题/模板调整等入口已统一接入快照与版本链路
- `resume` 保存接口补齐 `language` 持久化，保证恢复与翻译后的状态保存一致
- 收紧 `save(forceVersion)` 语义，避免无改动时发送无意义的服务端写入
- 修正本地版本历史的保留上限逻辑，避免少保留一个版本

## 发布与交付

- 重新整理中英文 README，仓库默认 README 切换为中文
- 修复 Docker 中 Node / pnpm / build approvals 兼容性，确保容器构建可用
