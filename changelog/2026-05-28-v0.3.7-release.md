# v0.3.7

发布日期：2026-05-28

## 新功能

- 新增**服务端默认 AI 配置**，自托管 / Docker 部署可直接通过环境变量启用 OpenAI、Anthropic 或 Gemini
- 前端运行时会自动感知服务端 AI 配置，并将默认服务商与模型同步到设置界面

## 功能完善

- `AI_PROVIDER` 未显式指定时，服务端会自动选择首个已配置的模型提供商
- AI 模型列表接口改为复用统一配置解析逻辑，浏览器未填写 API Key 时也可直接读取服务端默认配置
- 聊天与设置流程优化：当服务端已配置 AI 时，用户可留空本地 API Key 直接使用
- 补充 `.env.example` 与 README 的 Docker 说明，明确服务端 AI 环境变量配置方式

## 发布与交付

- GitHub Release：`v0.3.7`
- Docker 镜像：`ghcr.io/lessup/jadeai:v0.3.7`
